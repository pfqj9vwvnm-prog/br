# Black Russia · онлайн-бот

Telegram-бот (aiogram 3), который опрашивает серверы Black Russia по UDP (SA-MP/CRMP query)
и показывает онлайн в виде интерфейса на инлайн-кнопках. Весь экран обновляется на месте — одним сообщением.

## Запуск
```
pip install -r requirements.txt
BOT_TOKEN=... python bot.py
```
`Procfile`: `worker: python bot.py` (без изменений).

## Структура
| Файл | Назначение |
|---|---|
| `bot.py` | точка входа, обработчики команд и кнопок |
| `screens.py` | все экраны, клавиатуры и навигация («маршруты» в callback_data) |
| `samp.py` | UDP-опрос, кэш, снимки данных, фоновый сбор истории |
| `storage.py` | избранное и история онлайна (JSON) |
| `servers.py` | список серверов и групп, русские алиасы для поиска |
| `config.py` | настройки из переменных окружения |

## Переменные окружения
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BOT_TOKEN` | — (обязательно) | токен бота |
| `X_LABEL` | `x2` | множитель события; пусто — не показывать |
| `CACHE_TTL` | `15` | кэш данных, сек |
| `FORCE_MIN` | `5` | мин. интервал между нажатиями 🔄, сек |
| `HISTORY_INTERVAL` | `300` | шаг записи истории онлайна, сек |
| `HISTORY_HOURS` | `24` | глубина истории для графиков, ч |
| `STALE_MAX` | `600` | сколько секунд показывать старые данные, если сервер молчит |
| `DATA_DIR` | `data` | папка для `favorites.json` и `history.json` |
| `MAX_FAVS` | `24` | лимит избранного на пользователя |
| `TZ_NAME` / `TZ_LABEL` | `Europe/Moscow` / `МСК` | часовой пояс и подпись |

## Добавить сервер
В `servers.py` допиши строку `NAME последний_октет` в нужную группу (строки `# Название` — это группы).
Для поиска по-русски можно добавить алиас в `_ALIASES_RAW`.

## Важно про хранение
На Heroku и похожих хостингах диск временный: избранное и история сбрасываются при каждом рестарте.
Чтобы они сохранялись, смонтируй постоянный том и укажи его путь в `DATA_DIR`.
